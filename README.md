# Bright Tech Education Website

A simple informational website for Bright Tech Education, showcasing ICT, coding, robotics, and digital skills classes for young learners.

## Overview

This project includes a landing page with sections for Home, About, Services, Contact, Enrollment, and a footer. It is built using static HTML, CSS, and JavaScript.

## Files

- `index.html` - Main website content and page structure.
- `style.css` - Styling for the layout, cards, buttons, and responsive design.
- `script.js` - JavaScript logic for navigation, animations, and interactivity.
- `images/` - Supporting images used throughout the website.

## Usage

1. Open index.html in a web browser.
2. Edit the HTML and CSS files as needed to update content and styles.
3. Add or replace images in the images/ folder.

## Notes

- The site uses Font Awesome icons via CDN.
- The Enrollment and Contact sections include forms for visitors.
- The website is designed for easy customization for Bright Tech Education promotions.
